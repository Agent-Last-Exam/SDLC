# Golden 完整目标接口描述规范

本文件是制作规范，不是要复制成目标接口答案的模板。

对配置中声明的每个实际接口边界，使用其原生格式交付完整目标定义，如 GraphQL SDL、OpenAPI、proto、事件 schema 或 CLI 参数/输出合同。

- 来源是固定最终实现的权威输入和生成配置；制作方可以读取目标，不能与待测 Agent 的 Base-only 权限混淆。
- 输出包含未变更的基线定义及最终变化，不只提供 diff 或片段；完整范围是声明边界，不扩成组织全部接口。
- 权威提供者、快照、工具版本、输入/配置/输出哈希、消费者和检查结果都登记。
- 多版本输入分别解释来源、用途及兼容；字节不同需分析实际使用合同，不自动当相同或不兼容。
- 接口合同中的 I ID 定位到此完整定义，语法、类型引用及消费者 operation 按适用工具检查。
- 权限、动态默认值和完成语义以真实实现/测试补充，schema 单独不足以证明。
- 关键冲突或生成入口缺失返回第二条修复，不能只改文档里的 schema 冒充目标已修复。
- 不适用依据在 document-plan/设计中记录；指定模板的必交项不能擅自省略。
