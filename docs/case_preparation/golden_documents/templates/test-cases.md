# Golden 测试用例格式

输出为 `test-cases.v1.csv` 或配置指定版本。版本、PRD/设计/接口依据及用例设计状态写在 Test/README，不在 CSV 前插标题或 Markdown。

| 列 | 说明 |
| --- | --- |
| 用例编号 | TC{nnn}，稳定且不复用 |
| 一级模块 | PRD 业务域名称 |
| 二级模块 | 活动需求“R{nn} · 标题” |
| 用例标题 | 陈述验证的具体行为 |
| 覆盖 | 至少一个活动 AC；可加实际设计/接口 ID，分号分隔 |
| 优先级 | 遵守 PRD 和指定模板，不高于所属需求 |
| 前置条件 | 身份、状态、数据和环境要求 |
| 操作步骤 | 编号分行，明确测试数据和动作 |
| 预期结果 | 与步骤对应的可观察结果 |

一个 TC 可覆盖多个 AC，但必须逐 AC 对应操作/预期；多个 TC 可以共同验证一个 AC。测试用例数与 AC 数不要求相同。

无活动 AC 的删除边界使用独立 guard-cases，不伪造已删除 AC。实际自动化覆盖和运行证据进入追踪/审核，不将设计完成写成测试执行通过。含逗号、双引号、换行的字段按 CSV 标准转义。
