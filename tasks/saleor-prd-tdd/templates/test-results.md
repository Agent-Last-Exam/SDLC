# 测试执行记录：{标题}

文件：test-results.{轮次}.csv
依据：测试用例 {版本}；Sprint {n}；测试轮次 {轮次}；被测代码 {commit / 构建号}

交付 CSV，第一行使用以下列名，不在 CSV 中添加标题、版本说明或 Markdown 标记。依据的版本与被测环境写在同轮测试报告中。

| 列 | 说明 |
| --- | --- |
| 用例编号 | TC{nnn}，取自本次使用的测试用例 CSV |
| 结果 | 通过 / 失败 / 阻塞 / 未执行 |
| 实际结果 | 执行后观察到的现象 |
| 证据 | 支撑该结果的请求/响应、日志、截图路径等 |
| 缺陷编号 | D{nn}，对应本轮测试报告中的缺陷条目 |

```csv
用例编号,结果,实际结果,证据,缺陷编号
```

测试用例中的每个 TC 在本文件恰好出现一行。结果为“失败”时，证据与缺陷编号必填；为“阻塞”时，实际结果写明阻塞原因。多个 TC 可指向同一缺陷编号。

含逗号、换行或双引号的字段使用 CSV 双引号转义。
