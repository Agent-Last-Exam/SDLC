# 测试用例：{标题}

文件：test-cases.{版本}.csv
依据：PRD {版本号}；前端技术设计 {版本号}；后端技术设计 {版本号}；接口契约 {版本号}；目标 schema {版本号}

交付 CSV，第一行使用以下列名，不在 CSV 中添加标题、版本说明或 Markdown 标记。首版文件名为 `test-cases.v1.csv`；依据的文档版本由交接记录关联。

| 列 | 说明 |
| --- | --- |
| 用例编号 | TC{nnn} |
| 一级模块 | PRD 业务域分组名，原文照抄 |
| 二级模块 | PRD 需求条目“R{nn} · {标题}”，原文照抄 |
| 用例标题 | 陈述句，写明验证什么 |
| 覆盖 | 至少一个 AC-{nn}-{m}；需要时追加 FD/BD/I 编号，分号分隔 |
| 优先级 | P0 / P1 / P2 |
| 前置条件 | 执行用例需要满足的条件 |
| 操作步骤 | 编号分行，测试数据写在步骤里 |
| 预期结果 | 编号与步骤对应 |

```csv
用例编号,一级模块,二级模块,用例标题,覆盖,优先级,前置条件,操作步骤,预期结果
```

编号发布后不重排、不复用，新增往后编号。用例优先级不得高于其所属需求（二级模块）的优先级。与 PRD、技术设计指同一事物时使用其名称和编号，不另起名。

含逗号、换行或双引号的字段使用 CSV 双引号转义。
