## 编码结果的限制

流程完成不等于业务验收通过。Agent 的开发交接报告明确记录：仍有未完成 P0 业务闭环和失败门禁，不具备全量验收或直接生产发布条件。资金混合回归、既有 OIDC 回归、全仓 lint/knip 等仍有失败。详见 test-handoff.md 中 D01—D09 及失败分类。

已封存开发自测日志包括 Core 新增整合集、公开输入回归、Dashboard 改动测试、类型检查等；这些是开发阶段自测，不能代替独立 QA 或真实外部集成验收。

## 性能诊断

Coding 从实际模型执行到封存约 108 分钟。3,080 次模型请求均返回 HTTP 200，未记录 relay_error/upstream_error。响应头等待中位数 5.116 秒、P90 10.501 秒；请求到模型结束中位数 8.35 秒、P90 21.424 秒。该延迟包含网络、网关排队和模型端处理，当前埋点无法分离。API 累计上报约 213 万输出 token，包含并发子 Agent 请求，不等于单主会话输出量。

本地 Read/Write/Edit 中位耗时约 0.06/0.04/0.10 秒，Bash 约 0.54 秒。由此推断，大量模型轮次、阅读/修改和多 Agent 整合是主要耗时来源；没有证据支持网络故障导致大量重试。不能据此断言网络零开销。
